# 快捷菜单目录多选实施计划

> 按用户已确认方案在当前工作区执行；不修改 Git 索引、历史、系统设置或真实云盘。

**目标：** 分类栏最右侧仅显示齿轮图标；逐层浏览并跨目录勾选最多五项，按勾选顺序保存，重新打开回显，清空恢复原生菜单。

**方案：** `guangya-folder-browser.js` 的 `select(initialItems)` 复用 FolderBrowser/useTree 与原生 NiceModal，新配置弹窗提供复选框，已选 N/5 放在底栏清空按钮左侧，不显示已选目录列表；原移动/复制保持单选。`guangya-home-button.js` 将所选目录的 id/name/path 数组存入新 localStorage 键，严格校验唯一 ID 与五项上限；旧父目录配置不自动转换。菜单直接展示保存项，不再读取父目录，也不做偏好排序。

**技术：** 现有原生 React、目录组件、HTTP 与 DOM；不增加依赖。

## 边界

- 官方接口从当前安装包只读核对；模拟请求仅作用于隔离页面。
- 默认每次打开选择器从根目录浏览，避免对未加载的深层目录 ID 假装完成定位。
- 真实云盘、真实账号切换与原生最终视觉需用户实机验收；本轮不自动重注入或构建应用。
